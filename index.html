Keyboard shortcuts

EnterCreate new item below
Tab / Shift+TabIndent / outdent item
↑ / ↓Jump to previous / next item
Shift+↑ / ↓Mark items; inside an item, select text
Alt+↑ / ↓Move item (with children) up / down
Alt+→ / ←Zoom into / out of an item
Ctrl+.Collapse / expand item
Del / Ctrl+DelDelete marked or empty items (on text level, delete text)
Ctrl+KInsert math (wrap selection in $...$)
Ctrl+IImport list
Ctrl+EExport list
Ctrl+HShow this help dialog
Ctrl+M then 1–9Color item or all marked items
Ctrl+M then same numberRemove color
